# linear-actions

Post comments and perform workflow automations on Linear issues directly from GitHub Actions. The first supported command, `comment`, posts a comment to a Linear issue and optionally deduplicates identical messages.

## Usage

```yaml
jobs:
  notify-linear:
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v4
      - name: Comment on Linear issue
        uses: your-org/linear-actions@v1
        with:
          api-key: ${{ secrets.LINEAR_API_KEY }}
          issue-key: ABC-123
          body: "Preview available at https://env.example.com"
          dedupe: true # optional, defaults to true
```

## Inputs

| Name        | Required | Default | Description |
|-------------|----------|---------|-------------|
| `api-key`   | Yes      | —       | Linear API key with access to the issue. |
| `issue-key` | Yes      | —       | Linear issue identifier (e.g. `ENG-42`). |
| `body`      | Yes      | —       | Comment text to post. |
| `dedupe`    | No       | `true`  | Skip posting when the issue already contains an identical comment. |
| `command`   | No       | `comment` | Reserved for future sub-commands. |

## Behavior

1. Looks up the issue UUID from the public key (e.g. `ABC-123`).
2. When `dedupe` is enabled, fetches existing comments and skips if the exact `body` already exists.
3. Posts the comment through the Linear GraphQL `commentCreate` mutation.

## Development

```bash
npm install
npm test          # run unit tests
npm run build     # compile TypeScript and bundle with ncc
```
